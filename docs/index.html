Sincronización entre dispositivos

      
Tus notas, traducciones, glosario y progreso se guardan en un repositorio privado de tu GitHub y se sincronizan solos. Los PDF y tu clave de Gemini no se suben. 

      

        ¿Cómo lo configuro? (5 minutos, una sola vez)
        
    
          
  1. Crea un repositorio Private llamado techreader-datos en github.com/new.
    2. 
          
  2. Crea un token en GitHub → Fine-grained token:
            Repository access → Only select repositories → techreader-datos;
            Permissions → Contents: Read and write; vencimiento: 1 año.
    3. 
          
  3. Copia el token (empieza con github_pat_) y pégalo aquí abajo.
    4. 
          
  4. En tus otros dispositivos haz lo mismo, o importa un respaldo que incluya el token.
    5.
